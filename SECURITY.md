# Security Policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

- **Preferred:** [Open a private advisory](https://github.com/saucy-tech/home-hive-demo/security/advisories/new) — the thread stays attached to this repo.
- **Email:** brandon@saucy.tech

This is a personal project, so I can't promise a response time. I read every report and will tell you what I decide to do about it.

## Scope

The code in this repository and the demo it deploys at [home-hive-demo.brandonsauceda.workers.dev](https://home-hive-demo.brandonsauceda.workers.dev).

One thing I especially want to hear about: this is a sanitized copy of a private family app, and the sample week is invented. If you find real personal data anywhere in this repo or its history, that is a bug — please report it privately rather than posting what you found.

## Out of scope

- The private production app it was copied from. That runs behind Cloudflare Access and is not in this repository.
- Automated scanner output submitted without a working proof of concept.
